# Hermes

Portable Windows utility app (no installer) for a content creator. Personal use, public repo
`MegumiSharp/hermes`, unsigned exe is fine.

- Full spec: [docs/SPEC.md](docs/SPEC.md) — read before changing behavior. Done / to do (for the owner, Italian): [docs/STATUS.md](docs/STATUS.md), update it every tranche.
- Design: [design/mockups.html](design/mockups.html), chosen **01 Graphite / Amber**. App mark and icon: the owner's Anya logo (`src/assets/anya/face.png`, icons in `src-tauri/icons` via `npx tauri icon`), recoloured like the poses (Libbie art by Tyson Tan) by `scripts/anya-assets.mjs` (`--logo <png>` keeps the logo's light/dark contrast). Never use her dark versions (004 dark, 005 male, 011 math). After changing `src-tauri/icons`, touch `src-tauri/build.rs` before a local build: cargo otherwise keeps the old icon in the exe (CI builds are clean).
- Work in tranches (SPEC section 9); finish, test and commit one before starting the next.
  Done: T0–T12 (T12 = owner feedback round: info buttons, sidebar activity, non-blocking downloads, file tray,
  DirectML fallback, stats, viewer/zoom, gallery list view + title filter + per-file log).
  T13 = Downloads page (replaces sidebar Activity), live console per queue item, queue renders immediately on
  tool switch, per-tool Clear, parallel downloads setting (default 6) + shorter cooldown (1→15 min), low-priority
  tools, results always in the chosen folder, Video Downloader resolutions/container/Premiere/Mix, Spotify (spotDL),
  Video Converter (FFmpeg), Image Upscale images-only, gallery shows no list without previews.
  T14 = sidebar busy/done/failed dots, perf (verify cache, logs on demand, cached thumbs, tray diff redraw, rembg Gentle mode),
  AI models update check (Binaries page), Thumbnail Tester.
  T15 = Spotify official sources (Hermes checks spotDL's pick, replaces fan uploads with the official YouTube Music track),
  `liveStatus` feedback for probes, stage-weighted spotDL progress. SpotiFLAC (FLAC) was tried and dropped: its servers were dead (Oct 2026).
  T16 = Video Downloader audio: square cover, official lyrics (channel subtitles → ID3 USLT via `lyrics.rs`), WAV 48 kHz "Montaggio".
  T17a = every control drawn by Hermes (customizable select, `tooltip.ts`, scrollbars, number/date/color inputs), `scripts/ui-shots.mjs`.
  T26 = Gallery without preview (Download straight to the queue), cookies for any site asked once on the first download, no false rate limits from local tools, one bar for multi-pass tools.
  T25 = faster Gallery (one gallery-dl pass with every filter as one expression, `gallery-filter.ts`), E-Hentai/ExHentai cookies.

- **Rule: nothing long-running may block the UI.** No progress modals: use `startTask()` (activity.ts) so it shows
  on the Downloads page/badge; every tool stays usable meanwhile. Module state that must outlive navigation lives at module scope. Owner's manual test checklist: [docs/TEST-TODO.md](docs/TEST-TODO.md).
- **Rule: every field/choice/pending list of every tool must survive closing the app** (`memory()` in core.ts;
  URLs re-probe on reopen). New tools must follow it.

## Conventions
- UI text in English. Owner talks in Italian.
- Minimal, dark, one accent color, Lucide line icons. No emoji anywhere in UI.
- **UI rule: nothing may look like Windows.** Every control uses the shared styles in `styles.css`: `<select class="select">`
  (customizable select, drawn picker + Lucide chevron), `.field`/`input.num`, `.check`, `.switch`, `.btn`, `.chip`, `.seg`,
  `.tabs`; tooltips are any `title` (`tooltip.ts` draws them); scrollbars are thin and dark globally. New controls get a shared
  class, never browser defaults. Spacing: page gap 14px, card padding 12-14px, field height 36px (30px in dense panels),
  labels `.field-label` above fields. After any UI change run `node scripts/ui-shots.mjs` and **look at every screenshot**
  in `test-output/ui` (each page and each dropdown open); it also fails if a `<select>` renders natively.
- **UX rule: every wait shows feedback.** Anything slower than ~1 s that isn't a queue job uses `liveStatus()` (common.ts):
  what it is doing, n / total when known, elapsed seconds, Details with the tool output.
- Each module is self-contained; adding one touches only the registry in `src/main.ts`.
- Everything the app writes lives in `hermes-data/` next to the exe. Never commit it.
- External tools run hidden (`binaries::NO_WINDOW`), never a console window.
- Don't write project files with PowerShell `Set-Content`/`Out-File` (PS 5.1 adds a UTF-8 BOM that breaks JSON). Use the Write/Edit tools or node.
